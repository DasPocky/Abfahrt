# Sicherheit

## Sicherheitslücke melden

Bitte **kein öffentliches Issue** anlegen. Melde Sicherheitsprobleme vertraulich über
[„Report a vulnerability“](https://github.com/DasPocky/Abfahrt/security/advisories/new).

Bitte gib an:
- betroffener Bereich (App, Worker-API, CI)
- Schritte zum Nachstellen
- mögliche Auswirkungen

Wir melden uns so schnell wie möglich. Es ist ein privates Hobbyprojekt, deshalb gibt es keine feste Reaktionszeit.

## Unterstützte Versionen

Nur die aktuelle Version auf `main` bzw. die produktive Installation.
